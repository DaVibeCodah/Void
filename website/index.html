Architecture

7 LAYERS.
NOTHING PASSES.

Every request is processed through a sequential pipeline. Each layer adds signals. The scorer decides. The challenge engine acts.

L1
Kernel / eBPF (XDP + TC)
SYN floods die at the NIC — before the kernel network stack even sees them. TCP fingerprints (window size, MSS, TTL, WSCALE) extracted from every SYN packet via eBPF programs running at line speed. On Windows: software-mode WFP filter.
XDP_DROP SYN Flood TCP Fingerprint IP Blocklist NIC Offload
L2
Edge Proxy — Rust
TLS termination with full ClientHello parsing for JA3 and JA4 fingerprints. HTTP/2 SETTINGS frame fingerprinting and pseudo-header order analysis. GeoIP + ASN classification. Multi-scope rate limiting backed by Redis.
JA3 / JA4 HTTP/2 FP TLS Inspect Rate Limit ASN Lookup
L3
Request Analysis Engine
URL normalization (handles all 10+ encoding bypass variants), header anomaly detection, honeypot matching, timing jitter measurement, slow HTTP attack detection, JSON entropy analysis, parameter pollution detection.
URL Normalize Honeypot Timing Jitter Slow HTTP HPP Detect
L4
Behavior / ML Engine — Python
Five parallel ML models: Isolation Forest (anomaly detection), LSTM (session navigation sequences), Transformer (cross-session coordination), DBSCAN (fingerprint clustering), Graph/Louvain (botnet community detection). All async, 5ms P99 budget.
Isolation Forest LSTM Transformer DBSCAN Graph Engine
L5
Client Challenge Engine — JS + WASM
Browser telemetry collection (mouse entropy, scroll inertia, keyboard rhythm, focus events). Canvas / WebGL / Audio fingerprinting. Automation framework probes. Proof-of-work SHA256. WASM compute challenge. All challenge assets inlined — zero extra requests under DDoS.
Mouse Entropy Canvas FP WebGL FP PoW SHA256 WASM Task
L6
Scoring & Decision Engine
30+ weighted signals aggregated into a risk score 0–100+. Each signal weight is continuously adjusted by the nightly ML retraining loop based on precision/recall metrics from confirmed attack logs.
Score 0–100+ Allow Challenge Block Adaptive Weights
L7
Intelligence & Feedback Loop
Attack signatures auto-promoted from ML detections to fast edge rules. Nightly model retraining on confirmed labels. Threat intel feeds (Spamhaus, AbuseIPDB). TOR exit list refresh every 30 minutes.
Auto-Retrain Threat Intel Sig Evolution Self-Optimize

Detection Surface

NOWHERE
TO HIDE.

Signals collected across every layer — network, transport, application, and behavioral. Bots fail on at least one.

⏱
Timing Jitter Analysis
Bots fire at deterministic intervals. Humans don't. Inter-request stddev below 2ms across 5+ requests = zero jitter flag.
interval_stddev cv_ratio periodicity
🖱
Mouse Entropy
Real users show Brownian-like cursor physics. Bots move in straight lines with zero acceleration variance and no teleport events.
curve_entropy accel_variance teleport_count
🎭
Automation Frameworks
Puppeteer, Playwright, Selenium, headless Chrome. Detected via navigator.webdriver, missing plugins, JS engine anomalies, Math.random entropy.
navigator.webdriver plugin_count=0 fp_precision
🔒
TLS Fingerprinting
JA3 and JA4 fingerprints from raw ClientHello. Cipher suite order, extension order, ALPN, elliptic curves. Mismatch with declared User-Agent = suspicious.
ja3_hash ja4_hash cipher_order
📡
HTTP/2 Fingerprinting
Chrome uses :method :authority :scheme :path. curl reverses the order. SETTINGS frame values identify the exact client library. Divergence = penalty.
pseudo_header_order settings_frame window_increment
🌍
Geo Velocity
Germany → Japan in 60 seconds. Haversine distance / elapsed time > 1000 km/h = impossible. Session flagged immediately.
haversine_km speed_kmh impossible_flag
🕸
Botnet Clustering
100 IPs, identical canvas hash, identical WebGL fingerprint, different geos. DBSCAN + Louvain community detection finds the farm and blacklists all members.
canvas_cluster community_id homogeneity
📈
Distributed Low-Rate DDoS
100,000 IPs × 1 req/10s = 10,000 RPS. Invisible to per-IP limits. Transformer model detects cross-session coordination. EWMA baseline detects the spike.
global_rps_spike ip_entropy coordination_score
🍯
Honeypots & Canaries
/.env, /.git/config, /wp-login.php, /api/v0/users, hidden CSS links in HTML. Humans never reach them. Bots always do. +50 score on contact.
honeypot_hit canary_triggered css_trap
Machine Learning

FIVE MODELS.
ONE VERDICT.

All models run in parallel per request. Results fuse into a single ML score contribution. All retrain nightly. No labeled data required to start.

Isolation Forest
Unsupervised Anomaly
35-feature vector. Isolates outliers in high-dimensional space. No labels needed. Detects novel attacks before signatures exist.
LSTM + Attention
Sequence Classifier
Session endpoint sequences. Humans navigate logically. Bots jump to /api/data directly. Bidirectional LSTM with multi-head attention.
Transformer Encoder
Coordination Detector
Cross-session window analysis. Finds distributed attacks where per-IP rate is clean but global coordination is unmistakable.
DBSCAN
Fingerprint Clustering
Density clustering on fingerprint vectors (canvas, WebGL, fonts). Finds bot farms using identical browser configs across thousands of IPs.
Graph + Louvain
Botnet Detection
Traffic as a multigraph. IP→Fingerprint→Session→Endpoint edges. Community detection finds coordinated clusters invisible to per-request analysis.
Platform Support

RUNS ON
WINDOWS TOO.

eBPF is Linux-only. On Windows, Vo!d's kernel layer is replaced by a software-mode WFP (Windows Filtering Platform) shim. All detection layers above L1 are 100% identical on both platforms.
